# BFS — কোন জিনিস কোন ফাইলে বদলাবেন

VS Code-এ খুলতে **`BFS.code-workspace`** ফাইলে ডাবল-ক্লিক করুন। বাম পাশে দুটো ফোল্ডার দেখাবে:

- **🌐 Website**: ছাত্রদের ওয়েবসাইট, লাইভ ঠিকানা https://bfsem.netlify.app
- **🗂 CRM + Student Portal**: অফিসের CRM, লাইভ ঠিকানা https://bfsam-crm.netlify.app

> ব্যাকআপ ফোল্ডার, আপলোডের zip আর ব্যক্তিগত PDF লুকানো থাকে, যাতে ভুল করে বদলে না যায়।

## বদলানোর পর: আগে নিজের কম্পিউটারে দেখুন

VS Code-এর মেনু **Terminal → Run Task… → "▶ Website + CRM লোকালি চালু করো"**। ব্রাউজারে সাইট খুলবে।

> ⚠️ লোকাল সাইটও **আসল ডাটাবেস** ব্যবহার করে। টেস্ট করার সময় ভুয়া লিড দিলে CRM-এ সেটা আসল লিড হয়ে যাবে, পরে মুছে দিন।

## তারপর অনলাইনে তুলুন (Netlify)

1. VS Code: **Terminal → Run Task… → "📦 আপলোডের ফোল্ডার বানাও"**
2. app.netlify.com → **bfsem** (ওয়েবসাইট) বা **bfsam-crm** (CRM) → **Deploys**
3. `Downloads/BFS-UPLOAD/website` (বা `crm`) ফোল্ডারটা পেজের নিচের বক্সে টেনে ছাড়ুন। ১০–২০ সেকেন্ডে লাইভ হয়ে যায়।

> শুধু যে সাইটের ফাইল বদলেছেন সেটাই তুলুন। `js/data.js` বা `CRM Site/js/config.js` বদলালে **দুটোই** তুলুন, কারণ এগুলো দুই সাইটেই থাকে।

## ভুল হলে

- Netlify → প্রজেক্ট → **Deploys** → আগের যেকোনো deploy → **Publish deploy**। সাথে সাথে আগের অবস্থায় ফিরে যায়।
- নিজের কম্পিউটারের পুরোনো কপি আছে `.backup-…` ফোল্ডারে।
