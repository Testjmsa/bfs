BFS ওয়েবসাইট — কীভাবে এডিট করবেন
====================================

পেজগুলো (আলাদা আলাদা):
  index.html         → হোম (Why Malaysia, ফ্রি টুলস, ইউনিভার্সিটি লোগো, টিম)
  universities.html  → ইউনিভার্সিটি ও ফি (লোগোতে ক্লিক করলে পপআপে তথ্য + সব প্রোগ্রাম)
  eligibility.html   → ফ্রি Eligibility Check + নিচে সাবজেক্ট কুইজ
  cost.html          → খরচ ক্যালকুলেটর
  visit.html         → অফিস ভিজিট বুকিং (ক্যালেন্ডার + ম্যাপ)
  about.html         → টিম (ছবিসহ), সার্ভিস, প্রশ্ন-উত্তর
  dashboard.html     → স্টুডেন্ট ড্যাশবোর্ড

ফাইল:
  js/data.js   → ⭐ সব তথ্য: ফোন, ঠিকানা, টাকার রেট, ইউনিভার্সিটি, প্রোগ্রাম ও ফি, FAQ, কুইজ
  js/i18n.js   → ⭐ ওয়েবসাইটের সব লেখা — প্রতিটা লাইনে [বাংলা, English]
  images/logos/      → ইউনিভার্সিটির লোগো (ফাইলের নাম = ইউনিভার্সিটির id, যেমন segi.png; Taylor's = taylors.svg)
  images/team/       → টিমের ছবি
  fonts/             → Li Ador Noirrit (বাংলা ফন্ট)

data.js-এ যা বদলাবেন:
  CONFIG.chatWhatsapp  → লাইভ চ্যাট ও বুকিং যে নাম্বারে যাবে (এখন 8801884098203)
  CONFIG.myrToBdt      → ১ রিংগিত = কত টাকা (এখন ৩১.৫)
  CONFIG.emgsDefault   → যে ইউনিভার্সিটির EMGS/ভিসা ফি জানা নেই, তার আনুমানিক ফি (এখন RM 2,500)
  EMGS = { ... }        → ইউনিভার্সিটি অনুযায়ী EMGS/ভিসা ফি (নতুন ফি জানলে এখানে যোগ করুন)
  CONFIG.tawkId        → সাইটের ভেতরে কাউন্সেলরের লাইভ চ্যাট (নিচে দেখুন)
  CONFIG.officeDays / officeSlots → অফিস খোলার দিন ও সময়
  CONFIG.sheetUrl      → Google Sheet লিংক (google-sheet-script.txt দেখুন)

নতুন প্রোগ্রাম যোগ করতে — ইউনিভার্সিটির programs: [ ... ] এর ভেতরে একই নিয়মে লাইন:
  ["B","business","Bachelor of ...", 3, 45000],
   লেভেল: E=English C=Certificate F=Foundation D=Diploma B=Bachelor M=Master P=PhD
   বিষয়: business it engineering medical health design hospitality education psychology law science arts english
   তারপর: বছর, ফি (RM)। ফি-র রেঞ্জ হলে শেষে আরেকটা সংখ্যা দিন, যেমন 27000, 45000

যে ইউনিভার্সিটির ফি দেওয়া আছে: SEGi (২০২৬), INTI Subang (২০২৫), Universiti Malaya (২০২৫/২৬),
  City University (২০২৫ বাংলাদেশ প্রোমো), Lincoln (২০২৬ প্রোমো), ALFA (২০২৫), UCSI (পুরনো শিডিউল — আনুমানিক)
বাকি ইউনিভার্সিটির ফি-ফাইল পেলে একই নিয়মে যোগ করা যাবে।

ফাইল বদলানোর পর নতুন ভার্সন সবার কাছে দেখাতে: html ফাইলগুলোতে ?v=4 কে ?v=5 করে দিন।

ওয়েবসাইটের ভেতরে কাউন্সেলরের লাইভ চ্যাট চালু করতে (ফ্রি):
  ১. tawk.to সাইটে ফ্রি অ্যাকাউন্ট খুলুন
  ২. Administration → Chat Widget → Direct Chat Link থেকে "propertyId/widgetId" অংশটা কপি করুন
     (লিংকটা দেখতে এমন: https://tawk.to/chat/65ab12.../1hk2...  → শেষের অংশটুকু)
  ৩. js/data.js-এ tawkId: "" এর ভেতরে বসান
  তারপর স্টুডেন্ট অ্যাসিস্ট্যান্টের সাথে কিছুক্ষণ চ্যাট করলে চ্যাট আপনার Tawk অ্যাপে (মোবাইল/কম্পিউটার) চলে আসবে,
  আপনি সাইটের ভেতরেই উত্তর দিতে পারবেন। tawkId না দিলে চ্যাট WhatsApp-এ (পুরো কথোপকথনসহ) চলে যায়।
নতুন (v10):
  - শুধু RM দেখায়, টাকা (৳) কোথাও দেখায় না। বাজেটের অপশনও RM-এ।
  - WEB_PROGRAMS (data.js-এর শেষে) → যেসব ইউনিভার্সিটির ফি-ফাইল নেই, তাদের Google/শিক্ষা-পোর্টাল থেকে নেওয়া আনুমানিক ফি।
    ইউনিভার্সিটির নিজের ফি-ফাইল পেলে এখানে বদলে দিন।
  - VISA_RENEW → প্রতি বছরের ভিসা রিনিউ খরচ। লম্বা কোর্সে (MBBS ৫ বছর) মোট ভিসা খরচ বেশি হয়।
  - js/sketch.js → মালয়েশিয়ার স্কেচ (টুইন টাওয়ার, KL টাওয়ার, জবা ফুল, প্লেন)।

EMGS / ভিসা ফি আপডেট (v13):
  - js/data.js-এ const EMGS = { ... } — প্রতিটা ইউনিভার্সিটির ভিসা ফি তাদের অফিশিয়াল ওয়েবসাইট থেকে নেওয়া (২৮ অক্টোবর ২০২৬)।
  - প্রতিটার পাশে url: আছে — ফি বদলেছে মনে হলে ওই পেজ খুলে নতুন সংখ্যা rm:-এ বসান।
    (সাইটে "EMGS / ভিসা ফি"-র পাশের ছোট্ট "°" চাপলেও ওই পেজ খুলবে।)
  - inFee: true মানে প্রোগ্রামের মোট ফি-তে ভিসা ফি আগেই ধরা (SEGi, Cyberjaya) — খরচে আবার যোগ হবে না।
  - কোন ফি কোথা থেকে নেওয়া, পুরো তালিকা: FEE-CHANGES.txt
